# AppVid visual redesign plan

## Direction contract

AppVid is a local production desk for turning mobile recordings into store-ready previews. The experience uses a graphite work surface, a single electric-blue interaction language, compact operational panels, and a clear hand-off from source recording to export. The preview and timeline remain the product's visual centre; privacy is presented as a production constraint, not a marketing badge.

## Milestones

- [x] **M1: Import desk** — Replace the centered landing hero/card stack with a task-first production desk that makes import the dominant action.
- [x] **M2: Editor workspace** — Apply the same hierarchy to the preview, timeline, inspector, and toolbar surfaces.
- [x] **M3: Responsive and finish review** — Validated narrow layouts, accessibility, and visual consistency with Playwright at 320px, 390px, 768px, and desktop widths.
